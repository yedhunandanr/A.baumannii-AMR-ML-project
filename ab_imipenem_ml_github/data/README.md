# Data

This directory intentionally does not include raw genome assemblies or phenotype data.

For reproducibility, document:
- The source database and dataset query.
- Retrieval date and accession/genome identifiers.
- The phenotype field, measurement units, and breakpoint guideline/version.
- Inclusion/exclusion rules and any deduplication.
- The exact filenames expected by each script.

Only redistribute source data if its terms permit it. Prefer a small, documented manifest of accession IDs over checking raw sequence files into Git.
